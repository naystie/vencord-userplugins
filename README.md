# vencord-userplugins

my [vencord](https://vencord.dev) user plugins. each has its own repository; clicking on a name will lead you there

| plugin | what it does |
| --- | --- |
| [voiceLeveler](https://github.com/naystie/vc-voiceLeveler) | makes everyone in voice about the same volume |
| [copyMentions](https://github.com/naystie/vc-copyMentions) | copy users, channels, roles and slash commands as raw mentions |
| [lastOnline](https://github.com/naystie/vc-lastOnline) | shows how long ago someone was last online under their name |
| [streamZoomFill](https://github.com/naystie/vc-streamZoomFill) | zoomed in streams fill your screen instead of a 16:9 box |

new to user plugins??? [here's how to install them](https://docs.vencord.dev/installing/custom-plugins/)
